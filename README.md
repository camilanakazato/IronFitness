# Site Iron Fitness CTI

Página institucional para uma academia de Cuiabá, MT. Projeto de **portfólio**, inspirado em um negócio real e sem fins comerciais. Não há vínculo oficial com a empresa.

🔗 **Acesse o site:** https://ironfitnesscti.netlify.app/

## Sobre o projeto

O objetivo foi criar uma página de vendas para academia, com foco em quem acessa pelo celular. O visitante entende a proposta logo no topo, compara os planos e chega ao contato por WhatsApp em poucos toques.

## Seções da página

- **Início:** chamada principal com botão de contato
- **Planos:** mensal, trimestral, semestral e anual, cada um com botão para o WhatsApp
- **Modalidades:** atividades oferecidas
- **Sobre:** motivos para treinar na academia
- **Avaliações:** depoimentos de clientes
- **Contato:** WhatsApp, redes sociais e endereço com link para o mapa

## O que eu usei

- HTML, para a estrutura
- CSS, para o visual escuro com laranja e a adaptação a celular e computador
- JavaScript, para o menu do celular, a rolagem suave entre seções e o ajuste do layout em telas pequenas
- Google Fonts (Barlow e Barlow Condensed), para a tipografia
- Netlify, para a publicação

## Como foi feito

Este projeto foi desenvolvido com o apoio de ferramentas de IA (*vibe coding*). Meu papel foi definir o conceito, organizar o conteúdo e o visual, revisar o resultado e publicar o site.

## Como abrir no computador

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
